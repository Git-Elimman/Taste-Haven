What the project is
# Taste Haven Restaurant
A responsive restaurant website built for Taste Haven, a Nigerian restaurant focused on presenting its meals, services and brand online.

what the website is for
##About the Project
The website is a multi-page website designed to provide customers with information about the restaurant, its meals, services, and contact options.
The idea of the project is to vibe code a project from start to finish using chatgpt and use it as another way of learning, practically.

Technologies used
## Technologies used

##Experience using AI
As said earlier the goal is to try out vibe coding with chatgpt and learn whilst at it. As such, I did not copy and paste, rather I typed each line of code.
Doing so has enabled me learn a handful of things that I didn't know before and made me understand some concepts that I had seen in video tutorial overtime.

I've also gotten to understand chatbot usage more, during the period

It's been a month since I started. I thought using AI would enable me complete it in a month or less, but that hasn't been the case. Because I am using the
free version, I've had to wait for hours to get back tokens to continue the work. Plus, because it's a free version, I also am not using chatgpt at its best.

We started the code from begining, twice, for reasons I do not fully understand, and it kept using different class names that weren't in the html. Therefore, 
I had to be more observant and present in my typing.

I have seen, practically, the importance of knowing the basics or knowing what you want before having AI create it for you. If I did not have a working 
knowledge of html and css, I wouldn't have understood what was going on.
